# 岗位图谱子系统 · 项目介绍

> 本文替代早期的「职途AI — Spring Boot + MyBatis + MySQL」宣传稿。旧稿描述的前后端登录模块
> 与智谱 GLM、Element Plus、`/dashboard` `/jobs` 等路由在本仓库中并不存在，已整体作废。

## 1. 定位

服务外包创新创业大赛 A13 赛道「岗位图谱组」的交付物，作为 ICT 赛题 2 主工程的辅助模块，
提供**结构化岗位画像 + 晋升/换岗图谱 + 语义相似检索**三件事的数据与接口。

## 2. 实际技术栈

| 层 | 选型 |
| --- | --- |
| Web 框架 | FastAPI 0.111 + Uvicorn 0.30 |
| 数据校验 | Pydantic 2.8（`job_schema.py` 定义岗位画像与路径模型） |
| 存储 | JSON 文件快照（`structured_job_data.json`，50 条岗位） |
| 语义检索 | `paraphrase-multilingual-MiniLM-L12-v2` 生成 384 维向量 + faiss 内积检索 |
| 图谱 | `job_graph.py` 内建静态晋升/换岗路径（50 个岗位全覆盖，每岗≥2 条横向换岗） |
| 数据加工 | pandas / numpy / scikit-learn |

## 3. 已实现能力

1. **岗位画像库**：50 条结构化岗位（岗位名、分类、职责、技能要求、能力标签等），字段见 `job_schema.py`。
2. **查询接口**：全量列表（分页 / 分类过滤）、单岗位详情。
3. **相似岗位检索**：文本向量化后在 faiss 索引中检索 top-K，返回相似度与匹配细节。
4. **职业路径**：给定岗位返回垂直晋升链与横向换岗链。
5. **数据加载健壮性**：数据文件路径多候选探测，缺失时显式报错（2026-11-16 修复：此前默认文件名与实际提交文件名不一致，导致所有接口静默返回空列表）。

## 4. 数据与验证现状

- 数据文件 `岗位图谱子系统/structured_job_data.json`：50 条岗位，53KB，随仓库提交。
- 已验证：数据加载层（`JobDatabase()` 读出 50 条岗位）。
- **未在本机验证**：HTTP 接口端到端（缺少 torch / faiss / sentence-transformers 依赖，需先 `pip install -r requirements.txt`）。
- 未对外提供公网服务，无鉴权、无限流；接入 AgentArts 前必须补网关级鉴权与限流。

## 5. 与主工程的关系

- 主工程 `01_ICT主工程` 通过 MCP 工具 `get_role_competency` 读取岗位能力数据，不直接依赖本目录的 HTTP 服务。
- 本模块不参与主工程的启动、构建与测试流程，改动互不影响。
