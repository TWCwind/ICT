# 职途AI - 大学生职业规划智能体系统

## 项目概述

职途AI是一个面向大学生的智能职业规划系统，通过AI技术为求职者提供从简历分析到面试辅导的全流程服务。系统采用前后端分离架构，前端使用 Vue 3 生态，后端采用 **Java Spring Boot** 与 **Python FastAPI** 双后端架构，集成了智谱AI大模型实现智能化服务。

---

## 技术栈概览

### 前端技术栈
- **核心框架**: Vue 3.5 + Vite 6
- **UI组件库**: Element Plus 2.9
- **状态管理**: Pinia 2.3
- **路由管理**: Vue Router 4.5
- **数据可视化**: ECharts 5.6
- **文档处理**: html2canvas + jsPDF、markdown-it
- **HTTP客户端**: Axios 1.7

### 后端技术栈
**Java后端（用户认证服务）**
- **核心框架**: Spring Boot 3.5.14 (Java 21)
- **安全框架**: Spring Security
- **持久层**: MyBatis 3.0.5
- **数据库**: MySQL

**Python后端（AI智能服务）**
- **核心框架**: FastAPI 0.104.1
- **ASGI服务器**: Uvicorn 0.24.0
- **AI模型**: 智谱AI SDK 2.0.1
- **数据处理**: Pydantic 2.5、NumPy、Pandas
- **向量检索**: sentence-transformers、scikit-learn、PyTorch 2.1.0
- **缓存**: Redis 5.0.1
- **认证**: PyJWT 2.8.0
- **ORM**: SQLAlchemy 2.0.23

## 前端框架最出色的三个方面

### 1. 高性能现代化开发体验 ⚡

基于 **Vue 3 Composition API + Vite** 构建的前端应用，具备卓越的开发体验和运行性能：

- **毫秒级热更新**: Vite 的原生 ESM 模块加载机制，实现瞬时热更新，大幅提升开发效率
- **Composition API**: 使用组合式 API 编写逻辑，提供更优秀的代码组织方式和 TypeScript 支持
- **Tree-shaking 优化**: 打包体积精简，首屏加载迅速，用户体验流畅

```javascript
// 典型的组合式 API 代码组织
import { computed, ref, onMounted } from 'vue'
import { useCareerStore } from '@/stores/career'

const careerStore = useCareerStore()
const resumeAnalysis = computed(() => careerStore.resumeAnalysis)
```

### 2. 企业级组件库与数据可视化 📊

集成 **Element Plus + ECharts**，打造专业的可视化界面：

- **丰富的 UI 组件**: Element Plus 提供 60+ 高质量组件，覆盖表单、表格、弹窗、导航等各类场景
- **深色模式适配**: 组件样式统一，支持主题定制，保持品牌一致性
- **专业图表库**: ECharts 实现雷达图、折线图、柱状图、关系图等多种可视化形式
- **响应式设计**: 自适应不同屏幕尺寸，支持 1366px、1440px、1920px 分辨率

```vue
<!-- 典型的数据可视化组件 -->
<el-card>
  <div ref="chartRef" style="width: 100%; height: 400px"></div>
</el-card>
```

### 3. 模块化 iframe 架构与多页面隔离 🧩

采用创新的 **ModuleFrame iframe 模块架构**，实现功能解耦和独立部署：

- **模块化设计**: 资源推荐、模拟面试、岗位图谱等功能模块独立开发、独立部署
- **安全隔离**: iframe 沙箱环境保护主应用，模块故障不影响整体系统
- **独立升级**: 各模块可单独更新，无需重新部署整个应用
- **权限精细控制**: 通过 `allow` 属性精确控制 iframe 内的摄像头/麦克风权限

```
frontend-vue/
├── public/modules/
│   ├── resources/     # 资源推荐模块
│   ├── interview/     # 模拟面试模块
│   ├── graph/         # 岗位图谱模块
│   ├── assessment/    # 职业测评模块
│   └── jobs/          # 岗位匹配模块
```

## 后端框架最出色的四个方面

### 1. 双后端架构：Java Spring Boot + Python FastAPI 🚀

**创新的双后端设计**，充分发挥两种语言的优势：

- **Java Spring Boot**: 负责用户认证、权限管理等核心业务，提供企业级稳定性和安全性
- **Python FastAPI**: 负责AI智能服务，利用Python丰富的AI生态实现向量检索、大模型调用
- **职责分离**: 各语言专注其擅长的领域，架构清晰，易于维护
- **高性能**: FastAPI 原生异步支持，轻松应对数千 QPS

```python
# FastAPI 异步端点示例
@router.post("/api/analysis/upload")
async def upload_resume(file: UploadFile):
    result = await analyze_resume(file)
    return {"success": True, "data": result}
```

```java
// Spring Boot REST 控制器示例
@RestController
@RequestMapping("/api/auth")
public class AuthController {
    @PostMapping("/login")
    public ApiResponse<LoginResponse> login(@Valid @RequestBody LoginRequest request) {
        return ApiResponse.ok("登录成功", userService.login(request));
    }
}
```

### 2. 大模型集成与向量检索能力 🤖

集成 **智谱AI** 和 **sentence-transformers**，实现智能分析和语义匹配：

- **GLM 大模型**: 调用智谱AI API 实现简历分析、面试评估、职业建议等智能化功能
- **向量嵌入**: 使用 sentence-transformers 生成文本向量，支持语义搜索
- **相似度计算**: 基于余弦相似度实现简历与岗位的智能匹配
- **RAG 架构**: 检索增强生成，提升回答准确性和专业性

```python
# 向量检索示例
from sentence_transformers import SentenceTransformer

model = SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')
embedding = model.encode("前端开发工程师岗位要求")
```

### 3. 企业级安全与认证体系 🔐

实现完整的安全防护机制，保障数据和隐私：

- **JWT Token 认证**: 无状态身份验证，支持分布式部署
- **密码加密**: bcrypt 哈希算法存储用户密码
- **API 权限控制**: 基于角色的访问控制 (RBAC)，细粒度权限管理
- **Spring Security**: 企业级安全框架，防护 CSRF、XSS 等攻击

```python
# JWT 认证示例
@router.post("/api/auth/login")
async def login(username: str, password: str):
    user = authenticate_user(username, password)
    access_token = create_access_token(data={"sub": user.username})
    return {"access_token": access_token, "token_type": "bearer"}
```

### 4. 数据持久化与缓存优化 💾

采用 **MySQL + Redis** 双存储架构，兼顾性能与持久化：

- **关系型数据库**: MySQL 存储用户数据、简历记录、匹配结果等核心数据
- **高速缓存**: Redis 缓存热点数据和计算结果，显著提升响应速度
- **ORM 支持**: SQLAlchemy（Python）和 MyBatis（Java）简化数据库操作
- **数据一致性**: 事务支持和并发控制，保证数据准确性

```python
# 数据库操作示例
from sqlalchemy.orm import Session

def get_user_resume(db: Session, user_id: int):
    return db.query(Resume).filter(Resume.user_id == user_id).first()
```
