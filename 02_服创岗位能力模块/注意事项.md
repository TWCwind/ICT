# 职途AI 前端功能模块开发注意事项

你是本项目的前端开发 Codex。请严格在当前项目基础上继续开发，不要重建项目，不要破坏现有后端接口。

## 项目定位

项目名称：基于AI的大学生职业规划智能体

系统定位：AI职业规划智能门户 + 求职服务平台，不是普通后台管理系统。

核心流程：

1. 用户登录
2. 上传或录入简历
3. 生成学生就业能力画像
4. 进行岗位匹配
5. 展示岗位图谱
6. 生成职业生涯发展报告
7. 支持资源推荐、职业测评、模拟面试、个人中心和系统设置

## 技术边界

当前前端已迁移为：

- Vue 3
- Vite
- Vue Router
- Pinia
- Axios
- Element Plus
- ECharts
- jsPDF
- Canvas
- FileReader

必须保持：

- 前端不得直接调用 OpenAI 或智谱 API
- 所有 AI 请求必须发给后端 RESTful API
- JWT Token 由 Pinia + localStorage 管理
- 后端接口规范不随意修改
- 不要恢复旧 HTML 作为主入口
- 不要删除原后端

## 统一页面要求

所有功能页必须满足：

- 中文界面
- 顶部导航栏保留 10 个功能入口
- 风格保持当前蓝白科技感、清晰、现代
- 不做传统后台管理风
- 不堆大段说明文字
- 页面要能用于比赛展示
- 所有按钮、上传、导出、发送等操作要有明确反馈
- 如果后端接口不可用，允许提供本地演示兜底数据，但必须提示用户



## 路由要求

请保持以下路由存在：

- `/dashboard` 展示页 / 工作台入口
- `/chat` 智能问答
- `/analysis` 简历分析
- `/jobs` 岗位匹配
- `/graph` 岗位图谱
- `/report` 生涯报告
- `/resources` 资源推荐
- `/assessment` 职业测评
- `/interview` 模拟面试
- `/user` 个人中心
- `/settings` 设置
- `/login` 登录注册

未登录访问功能页时跳转 `/login`。

## 接口调用要求

所有接口必须通过 `src/api/request.js` 的 Axios 实例调用。

请求时自动携带：

```js
Authorization: Bearer token
```

如果后端返回 401：

- 清除 Token
- 清除用户信息
- 跳转登录页

## UI 协作要求

多人开发时必须遵守：

- 不随意改全局主题色
- 不随意改顶部导航结构
- 不随意改路由守卫
- 不随意改登录状态存储 Key
- 不在组件里写死真实接口密钥
- 不覆盖其他组员页面
- 公共组件优先放在 `src/components`
- 接口封装优先放在 `src/api`
- 工具函数优先放在 `src/utils`

## 代码提交前检查

每次修改后必须执行：

```bash
npm run build
```

确认：

- 页面不白屏
- 路由可访问
- 顶部导航完整显示
- 登录后可以进入页面
- 控制台没有明显报错
- 后端不可用时前端不会崩溃
